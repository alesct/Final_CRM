## 프로젝트 소개

AdventureWorks 자전거 회사의 실제 판매 데이터를 분석하고, 머신러닝으로 미래 매출을 예측하는 CRM 인텔리전스 웹 애플리케이션입니다. 실제 데이터 현황 분석, AI 예측 시뮬레이션, 시즌별 마케팅 전략 추천, 크로스셀링 분석 기능을 제공합니다.

## 설치 및 실행 방법

### 1. 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 번역 캐시 사전 생성 (최초 1회만 실행)

```bash
python generate_translations.py
```

Google Translate API를 통해 영어·스페인어·러시아어 번역을 미리 생성하고 `translations_cache.json`에 저장합니다. 이후 앱 실행 시 즉시 로드됩니다.

### 3. FastAPI 백엔드 실행

```bash
uvicorn app_api:애플리케이션 --reload --port 8000
```

### 4. Streamlit 앱 실행

```bash
streamlit run home.py
```

### 첫 번째 페이지 — 매출 및 예측 리포트

#### 탭 1: 실적 현황 — 실제 데이터

- **KPI 카드 4개:** 총 매출액($23.42M), 총 주문 수량(109,842개), 평균 단가($212), 전체 레코드 수(84,350개) — 모두 CSV에서 직접 계산
- **서브카테고리별 총 매출 (가로 막대):** Road Bikes가 압도적 1위. 색상은 카테고리별 구분(파랑=Bikes, 초록=Accessories, 갈색=Clothing, 보라=Components)
- **국가별 총 매출 (가로 막대):** 미국($13M) > 캐나다($3.47M) > 호주($2.42M) 순. 미국이 전체 매출의 절반 이상을 차지하며, 해외 시장의 성장 잠재력이 높음을 보여줌
- **카테고리별 매출 비중 (도넛 차트):** Bikes 71%, Components 15%, Accessories 9%, Clothing 5%
- **세계 판매 지도 (월드맵):** Plotly Scattergeo로 국가별 매출을 버블 크기와 색상으로 표현. 미국 대비 해외 판매량 격차를 시각적으로 확인 가능 → 해외 마케팅 투자 근거

#### 탭 2: 예측 시뮬레이션 — 판매 계획

- **B2C / B2B 거래 유형 선택:** B2C는 Random Forest API 호출로 예측, B2B는 `수량 × 단가 × 0.85` 도매 할인 공식으로 계산
- **카테고리·서브카테고리 선택:** 선택 시 해당 제품의 평균 단가·원가 자동 입력
- **재무 카드:** 예측 총 매출, 총 제조 원가, 마진율, 순수익 표시. 순수익 플러스=초록, 마이너스=빨강
- **수량별 매출 추이 그래프:** 수량 변화에 따른 매출·원가·순수익 선 그래프
- **국가별 비교 막대 그래프 & 데이터 테이블:** 동일 조건에서 국가별 예측 매출·순수익 비교
- **3D 예측 곡면:** X=수량, Y=단가 범위(±50%), Z=AI 예측 매출. 드래그로 회전 가능

### 📅 두 번째 페이지 — 시즌별 전략 추천

상단 필터(시즌, 국가)를 선택하면 아래 모든 차트와 전략 카드가 실시간 업데이트됩니다.

#### 탭 1: 시즌별 AI 매출 예측

- **KPI 카드:** 전체 예측 총 매출, 전체 예측 순수익, 최고 예측 국가
- **국가별 예측 매출 막대 그래프:** 각 국가의 예측 매출·순수익 비교
- **3D 예측 곡면:** B2B 모드에서는 Z축이 순수익으로 전환되어 손익분기점 파악 가능

#### 탭 3: 고객 유형 분류 — B2C / B2B

주문 조건(카테고리, 국가, 수량, 단가, 원가, 월)을 입력하면 Random Forest Classifier가 해당 거래가 일반 고객(B2C)인지 도매 대리점(B2B)인지 예측합니다.

- **예측 결과 카드:** B2C 또는 B2B를 크게 표시, 색상으로 구분 (파랑=B2C, 갈색=B2B)
- **확률 도넛 차트:** B2C vs B2B 확률 분포 시각화
- **분류 모델 피처 중요도:** 주문 수량(27.5%), 제조 원가(25.2%), 제품 단가(24.8%), 카테고리(19.7%) 순으로 분류에 영향
- **모델 정확도: 99.99%** (Random Forest Classifier, 트리 100개, 80/20 분할)

> 주문 수량이 가장 중요한 분류 기준입니다 — 도매 대리점은 개인 고객보다 훨씬 많은 수량을 주문하는 경향이 있습니다.

자전거(주력 제품) 구매 고객에게 함께 구매할 수 있는 제품을 추천하여 추가 매출을 창출하는 전략입니다. 이 탭의 모든 데이터는 API 없이 CSV에서 직접 계산합니다.

- **KPI 카드:** Bikes 총 매출, 전체 매출 중 Bikes 비중(약 71%), 최다 동반 구매 카테고리
- **동반 구매 카테고리 막대 그래프:** 자전거 구매 고객의 동반 구매 카테고리 매출 순위
- **카테고리별 시즌 매출 패턴:** 봄·여름·가을·겨울별 카테고리 매출 분포
- **크로스셀 전략 추천 카드:** 카테고리별 구체적 마케팅 전략 + 주요 서브카테고리 표시
- **시즌 인사이트 카드:** 선택한 시즌의 최고 동반 구매 카테고리 요약

> **국가별 전략이 다른 이유:** 나라마다 기후와 문화가 다르기 때문입니다. 호주처럼 자전거를 자주 타는 나라는 소모품(타이어, 부품) 수요가 높고, 추운 나라는 의류·장갑 수요가 높습니다. 쿠폰·멤버십 할인으로 고객 재방문율과 충성도를 높이는 전략을 제안합니다.

## 데이터 전처리 요약

원본 AdventureWorks 데이터를 pandas로 불러온 뒤:

1. 필요한 컬럼만 선택
2. **IQR 이상치 제거** — Q1(하위 25%)~Q3(상위 75%) 범위를 1.5배 벗어나는 값 제거
3. **LabelEncoder** — 카테고리, 국가 등 텍스트 컬럼을 숫자로 변환
4. 결과물: `adventureworks_clean.csv` (84,350개 레코드)

## 주요 설계 결정

- **월드맵 시각화:** 미국과 해외 시장의 매출 격차를 직관적으로 보여주어 해외 마케팅 투자 근거 제시
- **3D 예측 곡면:** 수량과 가격이 동시에 변할 때의 매출 반응을 입체적으로 시각화
- **계절별 분석:** `Month_num` 컬럼이 전부 0인 데이터 버그로 인해 계절 가중치(봄 28%, 여름 26%, 가을 25%, 겨울 21%)를 적용한 추정치로 시각화
- **B2B 도매 할인:** API 호출 없이 `수량 × 단가 × 0.85` 공식으로 즉시 계산
- **번역 캐싱:** 배치 번역(translate_batch)으로 API 호출 횟수 최소화
